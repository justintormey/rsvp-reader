# Changelog

This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-18

SemVer baseline established.

- 2026-07-18: Initial commit — Flash Reader RSVP speed reader formalized into a repo (originally built in the claude.ai web interface as a downloaded HTML file). ORP-pivot word display, phantom-word peripheral context, `@rsvp` directive format with chapter table of contents, gesture + keyboard controls, localStorage persistence.
- 2026-07-18: Deployed live to demo.justintormey.com/rsvp-reader/ via the shared `justintormey.com` S3/CloudFront deploy pattern.
- Single-file vanilla HTML/CSS/JS, no build step, no backend; live and in real use, so baselined at 1.0.0.
